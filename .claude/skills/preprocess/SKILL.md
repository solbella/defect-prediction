# preprocess

## 언제 부르나
- 새 데이터를 받아 모델에 넣기 전에
- 전처리를 다시 하거나 점검할 때

## 무엇을 받나
- 데이터 파일
- 결과 열 이름과 그 열에서 1로 볼 값
- 학습용과 시험용을 나눌 비율 (안 주면 8대 2)

## 어떤 순서로
1. 빈칸이 몇 개인지 먼저 센다. 0개면 채우지 않고 그대로 넘어간다.
2. 빈칸이 있으면 그 열의 중앙값으로 채운다. 채운 뒤 0개가 됐는지 확인한다.
3. 글자로 된 열은 학습에서 빼거나 숫자로 바꾼다. 어느 쪽으로 했는지 말한다.
4. 결과 열을 0과 1로 바꾼다. 1이 몇 건인지 확인한다.
5. 학습용과 시험용으로 나눈다.

## 무엇을 내놓나
- 나뉜 학습용과 시험용
- 확인 숫자 네 가지: 빈칸 전후 개수 / 글자 열 처리 방식 / 나뉜 행 수 / 학습용·시험용 각각의 1 개수와 비율

## 항상 지킬 것
- 값을 지어내지 않는다.
- 행을 지우지 않는다.
