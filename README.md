# 반도체 공정 데이터로 불량 조기 판별

공정 계측 기록을 분석해 불량 가능성이 높은 흐름을 미리 걸러내는 프로젝트입니다.

## 폴더 구조

| 경로 | 설명 |
|---|---|
| `data/` | 분석에 쓰는 원본 데이터 (SECOM 반도체 공정 계측 데이터) |
| `day01/` ~ `day08/` | 학습 일차별 실습 폴더 (현재 day01만 진행 중, 나머지는 비어 있음) |
| `day01/lab01_review/` | pandas 기초 복습 실습 (표 만들기·정렬·그룹화 등) |
| `day01/lab02_workspace/` | 실습용 빈 작업 공간 |
| `day01/lab03_process-card/` | 반도체 공정(식각 등)을 조사하고 내 공정 카드로 정리하는 실습 |
| `.claude/` | Claude Code 설정 폴더 |
